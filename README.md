# Pocket Hackslash

iPhone向けリアルタイム2Dハクスラの最小開発環境です。外部ライブラリを使わないため、静的Webサーバーへ置くだけで動きます。

## 現在の機能

- 画面左の仮想スティックで8方向移動
- 画面右下のボタンで前方範囲攻撃
- 敵の自動出現と追跡
- HP、無敵時間、ゲームオーバーと再挑戦
- 経験値、レベルアップ、攻撃力と最大HPの成長
- PWA設定とオフラインキャッシュ

## 起動

ローカルでは、このフォルダを静的Webサーバーで公開します。例：`python3 -m http.server 8080`

GitHub PagesやChatGPT Sitesなどの静的ホスティングにも、そのまま配置できます。将来App Storeへ提出するときはCapacitorでiOSプロジェクト化し、最後だけMac/Xcodeでビルドします。
