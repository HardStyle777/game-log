# Skill Forge

『黄昏の継承者』を削除し、チェックポイントの設計を基に新規作成した放置スキルバトル試作版です。

## 初版で遊べる内容

- 1対1〜3体の自動連戦（戦闘間の待ち時間なし）
- 5枠のスキル発動順をタップで交換
- 三連斬・貫通突き・低空薙ぎ・飛込み斬り
- HP/CP自然回復と発動順に入る回復薬
- 装備ドロップ、1〜3個のランダムOP、要求レベル
- 力・敏捷・健康・知恵・知識・威厳・運
- レベルアップごとに4ポイント
- iPhone縦横対応、ローカル保存

index.html をGitHub Pagesで公開して、そのままiPhoneのSafariから遊べます。
