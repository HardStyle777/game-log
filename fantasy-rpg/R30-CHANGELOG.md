# R30

町は草木の中間色を深くし、青灰色の石畳と水面の反射に差をつけた。外装は建物ごとに、屋根、柱、開口部、庇、玄関段を描き起こした。

| 建物 | 外装 |
| --- | --- |
| 宿屋 | 青瓦の交差する屋根、木の梁と柱、二階の客室窓、宿の看板 |
| 道具屋 | コーラルの瓦、縞の幌、商品棚が見える大きなショーウィンドウ |
| 集会所 | 青緑の屋根と小塔、ステンドグラス、石の玄関ポーチと縦長窓 |
| 民家 | 段差のある赤瓦屋根、張り出しのある窓、花箱、小さな玄関庇 |

建物の絵は `town-houses.js` で3倍の画素密度に描画し、各建物の入口と地面の座標を使って配置する。街の配色素材は Pillow で `python3 fantasy-rpg/tools/recolor-town-r30.py` を実行して再生成できる。
