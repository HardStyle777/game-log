# 行動順式オート戦闘

## 状態
2026-09-14: mainから開発ブランチを作成。これは新しい開発用保存先であり、実行環境の復旧や既存素材の復元は未完了。mainにある従来のゲームと、本仕様の実装は区別する。

## 採用仕様
- 剣士1人対敵1〜3体。スキルと回復薬を並べた行動順で自動戦闘。
- 戦闘中も徐々にHP回復。勝利後の戦闘待ち時間は設けない。
- 力・敏捷・健康・知恵・知識・威厳・運。1レベルにつき4ポイント。
- 装備OPは最大3枠。スキルそのものにはOPを付けない。
- 元の全OP一覧と既存計算コードを復元して使う。未取得の一覧を推測で置き換えない。
- 強い割合OP、高段階OPは希少。攻撃速度OPは特に希少だが低段階は高段階より出やすい。
- OP付与後の装備要求LvがキャラLv+100を超える装備はドロップさせない。
- ドロップ、装備更新、武器育成。町には選択肢で入り、店で回復薬等を購入。
- シナリオは保留。

## グラフィック方針
三連斬り・突き・薙ぎ払い・飛び込みはユーザー採用。今ある素材を使って遊べる戦闘を優先する。斬り上げの磨き込みは優先しない。
愛着ある2Dドット剣士。剣は解剖学的右手。左右の腕、握り、肩との接続、足の接地を確認する。同じ斬り方を繰り返すだけの別技にしない。白い芯・金色の光・先細りして消える軌跡を重視する。
