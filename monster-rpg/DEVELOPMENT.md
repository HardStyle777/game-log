# ルミナ島のモンスター 開発引き継ぎ

ユーザーの目的：iPhoneブラウザで遊べる、ポケモン型のオリジナル2Dモンスター収集・冒険RPGを作り上げる。画像と音も実際の資産を生成して組み込む。最初の方向選択は「2D冒険RPG」。追加質問はしない。細かい決定は開発側で行う。

## 現在の実装
- 48×36タイルの4エリア、診療所、商店、長老の3クエスト。
- 16種 / 8属性、草むら遭遇、捕獲、星色個体、6体パーティ＋ボックス、Lv.10進化。
- 気力管理・奥義・防御・交代・薬を使うターン制戦闘。
- 4番人、エリア解放、2体編成の4番人、Lv.23〜25の3体編成の最終守護竜、エンディング、クリア後収集。
- オートセーブ、前回バックアップ、戦闘中再開、JSON書き出しと読み込み。
- 生成済みmonster/worldスプライトシート、3曲のオリジナルBGMと9効果音。BGMは合成器から実際のMP3へ生成。人物の声の収録はしていない。
- iPhone向けタッチ十字キー、PCキーボード、オフラインキャッシュ。

## 検証
`npm test`：15テスト（純粋ロジック11＋DOM契約ハーネス4）。100シード×20戦闘の状態検査を含む。UIテストは実ブラウザではなく、生産UIのイベントハンドラを実行するDOMハーネス。
`npm run check`：JS構文。
画像2枚を目視確認。音声はffprobeでMP3/長さ/2チャンネルを確認する。

## 継続方針
- まず最新ソースとこのファイルを読み、毎回最重要の課題を1つ以上具体的に解決する。ソース修正→検証→記録→公開を1セットにする。
- 制限を解除するAPIや解除時刻取得はない。予定時刻の実行も利用制限に従う。制限があれば保存して次の実行で継続。無限の常時稼働や未着手作業を動作中と言わない。
- GitHub HardStyle777/game-log の monster-rpg/ が本ゲーム。既存の他のゲームと keiba-prediction には触れない。既存repoは当初合計約29MB、容量不足の根拠がないため削除不要。
- SitesプロジェクトIDは .openai/hosting.json の値を厳密に使う。Sites版が実際に遊ぶ配信版。GitHubへの鏡写しも最新に揃える。Secretsを保存しない。
- 新しいスプライト資産が必要ならImageGenで生成、プログラムで擬似的な絵を作らない。BGM/効果音は scripts/generate_audio.py で再現可能。
- 完成基準：通常プレイで開始→4エリア→最終勝利まで詰まらない、全16種が収集可能、保存再開に欠損なし、手機サイズで主要操作が可能、画像/音声に欠落なし、重大な既知バグなし。満たしたら継続タスクを停止し結果を報告。課題が残る間は未完成の範囲を具体的に書く。
