# 剣士の旅 — 戦闘統合版

`index.html` を HTTP サーバーで開く。ビルド済みの `core.js` を同梱し、npm/CDN は不要。

- 承認済みの2枚のスプライトと元の描画コードを使用。
- `restored/` は復元原本。`src/live_combat.cjs` は原本の計算式を維持した generator 版。
- `python playable/build.py` で原本から戦闘・描画コードとブラウザ用 bundle を再生成。
- `node --test playable/src/integration.test.cjs restored/revised_combat.test.cjs restored/revised_loot.test.cjs restored/town_shop.test.cjs`

## 戦闘

行動順は循環。使えない行動を飛ばす。通常攻撃でCPを獲得。戦闘終了時のHP・CP・回復薬・継続回復・状態異常・再使用時間・行動位置を次戦へ継承する。攻撃終了後の任意の待ち時間は設けない。致死攻撃も振り抜きの残り時間は行動時間に含める。

| 行動 | 物理倍率 | CP | 再使用 | 基準動作時間 | 命中タイミング |
|---|---:|---:|---:|---:|---|
| 三連斬 | 合計3.2 | 18 | 9秒 | 1.31秒 | 0.265 / 0.500 / 0.930秒 |
| 突き | 1.35 | 8 | 3秒 | 0.715秒 | 0.325秒 |
| 薙ぎ | 1.7 / 最大3体 | 12 | 5秒 | 0.735秒 | 0.315秒 |
| 跳び込み | 2.4 | 16 | 7秒 | 0.820秒 | 0.430秒 |
| 回復薬 | 最大HP30% / 6秒 | 0 | 15秒 | 0.5秒 | 使用終了後から継続回復 |

攻撃速度が動作時間と命中時刻を同率で短縮。OPによるスキルレベル補正は元モデルから使用。スキル自体にOPは付かない。三連斬の物理倍率と追加属性直接ダメージは3分割。状態異常などの発動抽選は各命中で行うため、この部分の組合せバランスは旧シミュレーションと同一とは主張しない。

## 成長・拾得・町

既存の全OPマスター、部位適性、抽選重み、必要Lv式、敵・属性・成長式を使用。装備抽選は敵1体につき10%。抽選後の必要LvがキャラLv+100を超えた品は除外する。無OP55%、1OP35%、2OP9%、3OP1%を基本とし、魔法品発見OP等の補正が別途入る。装備可能Lvは別判定。

町へは戦闘終了後に入る。装備・分解・育成・薬購入は町で操作。分解は1素材、育成は次の段階×20素材、最大+10。元モデルに従い部位の基礎寄与が段階ごとに4%増加。成長時のステータス配分は既存モデルの自動配分。

戦闘終了ごとに端末保存。途中で閉じると直前の戦闘終了時点から再開。旧簡易版の保存キーは変更・削除しない。非表示中は一時停止。敗北時は町で全回復。町での通常滞在には無料の全回復を付けない。

## 検証範囲と残件

既存ルールの100条件（Lv.1/10/100/500/1000 × 20乱数種）で旧実装と完全一致。新しい順序循環・3着弾・継続回復・振り抜きをテスト。
